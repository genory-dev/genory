# Getting started with Genory

Genory is a browser-based collection of developer tools, generators, validators and synthetic test-data utilities.

## Start with the web tools

Browse the available tools at:

https://genory.dev/tools

Typical use cases include:

- generating synthetic profiles for development and QA
- creating UUIDs and other identifiers
- producing address, phone and account-format test data
- validating structured values such as IBANs
- creating repeatable dummy datasets for demos and automated tests

## Use generated data responsibly

Generated output is intended for development, testing, demonstrations and QA.

Do not treat generated identities, addresses, bank details, phone numbers or other values as verified real-world information.

## API access

For supported endpoints and authentication details, use the official documentation:

https://genory.dev/docs

Never commit API keys to a public repository. Store them in environment variables or a secret manager.
